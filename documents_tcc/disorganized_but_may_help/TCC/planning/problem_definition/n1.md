# Defining what I will do in my TCC

## What

what's the objective of my TCC?

A project to calculate the results by using GPU acceleration and CPU bound methods for finding the best routes for delivery trucks, given a set of orders and a map of some city/region. The problem is a variant of the Vehicle Routing Problem (VRP) with pickup and delivery, time windows, and heterogeneous fleet. This means, it's a HFVRPPDTW and the goal is to minimize the total distance traveled by all trucks and maximize the number of orders delivered on time.
The aim is to calculate possible gains by using parallelization, GPU acceleration and different programming languages and compare them to existing methods. The language stack will be C++ CUDA and Python.
