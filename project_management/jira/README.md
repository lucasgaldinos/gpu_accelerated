## Usage

### Running the Sync Script

From the project root directory:

```bash
python project_management/jira/scripts/sync_jira_tasks_fixed.py --verbose
```

From the project_management/jira/scripts directory:

```bash
cd project_management/jira/scripts
python sync_jira_tasks_fixed.py --verbose
```

### Configuration

The sync script uses `project_management/jira/scripts/jira_sync_config.ini` for configuration. Update this file with your JIRA instance details if needed.

## Diagrams in TASKS.md

The file `project_management/tasks/TASKS.md` now auto-includes Mermaid diagrams generated by `sync_jira_tasks_fixed.py`:

1. Epics Timeline (`timeline` diagram) – chronological order of epics (phases).
2. Tasks Timeline – all issues (epics, tasks, stories) ordered by creation date with status icons.
3. Work Hierarchy Mindmap – epic → child task/story tree.

### Regenerating Diagrams

Run the sync script (optionally with `--dry-run` first):

```bash
python jira/scripts/sync_jira_tasks_fixed.py --dry-run --verbose
python jira/scripts/sync_jira_tasks_fixed.py --verbose
```

### Editing Behavior

- Do NOT manually edit the diagram sections between runs; they will be overwritten.
- Custom manual notes should go outside the sections titled:
  - `## Visual Timelines`
  - `## Work Hierarchy Mindmap`

### Mermaid Support Notes

- Timeline and Mindmap diagrams are experimental in Mermaid; GitHub renders them, but older viewers may not.
- Long summaries are truncated with ellipses to keep diagrams readable.
- Status Icons:
  - `✅` Done
  - `🟡` Not Done / To Do
  - `🔄` Epic pending
  - `📝` Regular task/story pending

### Adding Future Diagram Types

Extend helper methods in the sync script:

- `_generate_timeline_section`
- `_generate_hierarchy_mindmap`
- Add a new method and include it inside `_generate_visual_diagrams` aggregation.
