# PROJECT_MANAGEMENT

This directory contains all project management activities, task tracking, and workflow coordination for the GPU-accelerated TSP/VRP optimization project.

## Directory Structure

- **tasks/**: Detailed task specifications organized by phase
- **progress/**: Progress tracking, logs, and milestone reports  
- **planning/**: High-level project planning and roadmaps
- **github_integration/**: GitHub-specific files (issues, workflows, etc.)

## Key Files

- `TODO.md`: Quick task overview for VS Code Kanban Board integration
- `TASKS.md`: Detailed task specifications with learning objectives
- `TASK_BREAKDOWN_FRAMEWORK.md`: Framework for task management and GitHub integration

## Usage

This directory supports the teaching-oriented development approach with:

- Granular task breakdown (1-2 hour chunks)
- Progress tracking and validation
- GitHub issue integration
- Academic milestone management

See the files in this directory for detailed project management workflows and task specifications.
